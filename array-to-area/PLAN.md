## 教学设计

### 核心教学思路
以"方阵"（矩形排列的队列）为类比桥，连接乘法（每行人数×行数）与面积（长×宽）。学生通过三个 Canvas 互动动画，从"数人数"自然过渡到"数格子"，自己发现面积公式。

### 问题锚点
1. 运动会排方阵，每行8人排6行，总共多少人？
2. 一块长方形菜地，长8米宽6米，面积是多少？
3. 为什么长×宽就是面积？跟乘法有什么关系？

### 教学模块

| 模块 | 内容 | 互动 |
|:---|:---|:---|
| 前测 | 3道基础概念题 | 选择题+诊断反馈 |
| 模块1：方阵中的乘法 | 方阵排列→乘法算式 | **Canvas队列形成动画**（播放/逐行/重置） |
| 模块2：类比桥 | 方阵↔面积对照表 | 静态对照卡片+核心发现 |
| 模块3：探究实验 | 拖动滑块改变行列 | **Canvas实时网格**（方阵视角↔方格视角切换） |
| 模块4：公式总结 | 三栏公式对照 | 乘法口诀↔类比桥↔面积公式 |
| ConcepTest | 3道概念判断题 | 选择题+诊断反馈 |
| 分层练习 | 基础/进阶/挑战 | 三段式+参考解答按钮 |
| 易错点 | 3个常见坑 | 卡片展示 |
| 后测 | 3道进阶检测题 | 选择题+诊断反馈，可对比前测 |
| 小结 | 核心发现回顾 | 总结卡片 |

### Canvas 互动设计

1. **队列形成动画** (`canvas-formation`)
   - 6列×5行网格背景
   - 每格一个笑脸小人
   - 三个按钮：▶播放（自动逐行出现）、📋逐行添加（手动）、↺重置
   - 实时显示当前行数和总人数

2. **方阵↔面积网格切换** (`canvas-grid`)
   - 两个滑块：每行人数(1-10)、行数(1-8)
   - 两个切换按钮：👥方阵视角 / 📐方格视角
   - 方阵视角：金色笑脸小人网格
   - 方格视角：紫色交错方格+编号+测量箭头+面积标注
   - 实时更新下方算式和单位
