# TeachAny · K12 数学探究课件

基于 AI 互动动画的小学数学课件集合，覆盖几何与代数概念。

| 点线面：几何世界的元老 | v0.2.0 | 三年级 | Canvas · GeoGebra · TTS |
| 从方阵到面积 | v0.2.0 | 三年级 | Canvas · TTS |
| 长方形和正方形的周长 | v1.1.0 | 三年级 | Canvas · TTS |

## 技术栈

- 纯静态 HTML/CSS/JS
- Canvas 互动动画
- Edge TTS 语音旁白 (zh-CN-XiaoxiaoNeural)
- IntersectionObserver 滚动自动播放
- GeoGebra 几何实验集成
